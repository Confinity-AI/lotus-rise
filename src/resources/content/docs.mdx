Documentation gives structure to your product. It explains how things work, communicates decisions, and builds trust with users.

It lives within the same system as your landing page and dashboard, so your product and its explanation stay aligned.

![Documentation preview](/images/docs-01.jpg)

## MDX-based, fully integrated

All documentation is built with MDX, with Once UI components available across every page.

![Documentation preview](/images/docs-02.jpg)

- Write in simple markdown
- Use components where needed
- Keep structure consistent without extra effort

Content and layout are separated, so you can update documentation without breaking design.

## Designed for clarity and scale

Documentation is not just a page — it’s a system.

- Structured navigation and hierarchy
- Search-ready content
- Scalable as your product grows

![Documentation preview](/images/docs-03.jpg)

Whether you’re documenting features, APIs, or internal knowledge, everything stays organized and easy to extend.

## Connected to your product

Documentation works alongside:

- Landing page → sets expectations
- Dashboard → delivers functionality
- Shared components → ensure consistency

Users don’t leave your product to understand it — everything is part of the same experience.
