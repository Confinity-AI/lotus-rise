## First Session Rule

Do not start with a vague free-form request.

For the first serious build session:

- copy a prompt from `docs/AGENT_PROMPTS.md`
- fill in the project brief fields
- state the real audience, goal, required pages, and out-of-scope surfaces
- ask the agent to list the exact entrypoint files before editing
