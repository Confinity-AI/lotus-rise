# Cleanup Checklist

Use this after scaffolding and before deep implementation so the project does not carry template baggage forward.

## Core Rule

This repo should become one real product, not a template demo with edits on top.

## Remove Or Replace Early

- demo metadata and schema identity
- demo naming, descriptions, and contact details
- demo images and OG assets that are not part of the real site
- routes or sections that are out of scope
- unused content blocks, collections, or legal pages

## Keep Intentionally

- Once UI system wiring
- the real theme config file
- provider and layout structure
- high-quality Once UI interaction and spacing patterns

## Before Major Design Work

- decide which pages the real site needs
- remove or ignore starter surfaces that are out of scope
- tighten the project so future agents work on the real product, not on leftover demo structure
